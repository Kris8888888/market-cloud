# 大盘云图

A 股全市场热力图：按申万一级 → 二级行业分组，面积＝总市值，颜色＝当日涨跌幅（红涨绿跌，可切红蓝）。手机和桌面都能看。

## 文件
- `index.html` 页面本体（纯静态，无依赖）
- `treemap.js` 布局引擎（squarified treemap），`node test_treemap.js` 跑测试
- `data.js` 行业归属 + 市值快照，由 `update.js` 生成
- `update.js` 从腾讯财经抓 31 个一级、124 个二级行业及成分股，约 40 秒：`node update.js`

## 数据怎么更新
- 打开页面时会直接向腾讯行情（qt.gtimg.cn）拉全部股票的实时价、涨跌幅、市值；交易时段每 60 秒自动刷新，也可以点「刷新」。
- `data.js` 只决定「哪只股票属于哪个行业」和非交易时段的兜底数据，跑一次 `node update.js` 即可重生成；仓库里附了 GitHub Actions，每个交易日收盘后自动跑。

## 用法
- 点行业名放大到该行业，再点二级行业名只看它；左上角面包屑或 Esc 返回。
- 点股票看详情；桌面端悬停也有提示。
- 地址栏支持深链：`index.html#电子/半导体`。
- 左栏 / 顶部条可切换：全部 A 股、沪市主板、深市主板、创业板、科创板、北交所。
